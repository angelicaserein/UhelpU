## 维护规则

1. 新文档优先放入已有分类目录，不要再放到 docs 根目录。
2. 如果一个系统已经有独立目录，不再在其他目录保留重复副本。
3. docs 根目录仅保留本 README 和必要总索引文件。
4. 归档资料统一放 archive，不和当前主文档混放。
