# 玩家指南：创建和分享你的地图

欢迎使用地图编辑器！这个指南将教你如何从零开始创建一个有趣的游戏地图。

---

## 这个功能是什么？

地图编辑器允许你在游戏中创建自己的关卡。你可以放置各种游戏元素（平台、敌人、按钮等），然后保存并分享给其他玩家。其他玩家可以挑战你创建的地图，一起享受游戏的乐趣！

**简单三步**：

1. 进入编辑器 → 设计地图
2. 导出地图 → 上传到服务器
3. 分享链接 → 其他玩家可以玩

---

## 如何创建地图

### 第 1 步：进入编辑器

1. 在游戏主菜单中，找到"**地图库**"或"**用户地图**"按钮
2. 点击"**＋ 创建地图**"按钮（通常在右上角）
3. 你会进入编辑画面，左边是工具栏，右边是空白地图

### 第 2 步：选择工具放置元素

编辑器顶部有一排工具。点击选中一个工具，然后在地图上点击或拖拽放置：

**基础元素：**

- 🟫 **地面** - 最基本的踩踏平台，玩家可以在上面行走
- 🟪 **平台** - 浮空的小平台，可以跳跃到上面
- ⚫ **障碍物** - 坚硬的方块，可以推动或跳过
- 🔴 **尖刺** - 危险！接触会死亡，放在地形中制造难度

**传送类：**

- 🟢 **传送门** - 走进去就能到达目标地点
- 📍 **传送点** - 配合传送门使用，标记传送的终点

**交互类：**

- 🔵 **按钮** - 按踩踏按钮可以触发机关

**标记类：**

- 🏁 **存档点** - 玩家死亡后从这里重新开始
- 💬 **文字** - 显示游戏内的提示信息
- 👾 **敌人** - 会移动的敌人，碰到会死亡

**高级组合（自动包含按钮）：**

- ⚠️ **按钮+尖刺** - 踩踏按钮时尖刺开关
- 🚪 **按钮+传送门** - 踩踏按钮时传送门打开
- 📦 **按钮+平台** - 踩踏按钮时平台出现/消失

### 第 3 步：调整地图大小（可选）

单个地图可以是：

- **单房间**：一个屏幕那么大
- **多房间**：像一个关卡一样，可以向左右移动切换房间

在编辑设置中选择房间数。

### 第 4 步：测试地图

点击"**播放**"或"**测试**"按钮，用玩家的视角测试：

- ⬅️ ➡️ 移动
- **空格**或**W** 跳跃
- 调整难度和放置位置
- 确保没有卡住或不可通过的地方

### 第 5 步：保存和命名

给你的地图起一个有创意的名字，例如：

- "我的第一个挑战"
- "极限跳跃"
- "按钮谜题"

---

## 如何上传地图

1. 在编辑器中，点击"**导出**"或"**保存**"按钮
2. 输入地图名称和你的名字（作者名）
3. 点击"**上传**"
4. 等待上传完成（通常需要 1-2 秒）
5. 系统会显示"✓ 上传成功"

---

## 如何找到别人的地图来玩

### 查看地图库

1. 进入游戏，点击"**地图库**"或"**用户地图**"
2. 你会看到所有玩家上传的地图列表
3. 每个地图卡片显示：
   - 🎮 **地图名称**
   - 👤 **作者名**

### 搜索地图

用搜索框快速找到想要的地图：

- 按 **地图名称** 搜索：输入地图的关键词
- 按 **作者名** 搜索：输入作者的名字

### 挑战地图

1. 点击想要玩的地图
2. 点击"**开始游戏**"或"**挑战**"
3. 尝试通过关卡
4. 通关后可以看到用时，与其他玩家比较速度

## 地图里可以放哪些东西

### ✅ 完全支持的元素

| 元素名称    | 功能                    | 示例               |
| ----------- | ----------------------- | ------------------ |
| 地面        | 玩家可以站立和行走      | 地图底部           |
| 平台        | 需要跳跃才能到达的高度  | 中间浮空的方块     |
| 尖刺        | 接触即死，增加难度      | 地面上的小锯齿     |
| 传送门      | 进入自动传送到目的地    | 绿色的圆形         |
| 传送点      | 标记传送门的目的地      | 与传送门配合       |
| 按钮+尖刺   | 踩按钮时尖刺切换状态    | 需要踩按钮躲避     |
| 按钮+传送门 | 踩按钮时传送门打开/关闭 | 需要踩按钮才能传送 |
| 按钮+平台   | 踩按钮时平台出现/消失   | 踩按钮跳上浮空平台 |
| 存档点      | 死亡后从这里重新开始    | 中途休息点         |
| 敌人        | 移动的危险物体          | 左右巡逻的敌人     |
| 文字提示    | 显示游戏内提示信息      | "小心！"           |

### ❌ 不支持的元素（以及原因）

| 元素            | 为什么不支持                   |
| --------------- | ------------------------------ |
| NPC 对话        | 暂时无法存储自定义对话内容     |
| 自定义音效      | 用户地图只使用全局音乐         |
| 脚本/自定义逻辑 | 地图是纯数据格式，无法执行代码 |
| 自定义外观      | 无法改变游戏的美术风格         |
| 多行文本框      | 只能放简单的单行提示           |

## 常见问题解答

### Q：地图加载很慢怎么办？

**A：**

- 检查网络连接
- 如果是第一次加载，可能需要等待 2-5 秒
- 刷新页面重试
- 如果持续缓慢，可能是服务器问题，请稍后再试

### Q：为什么按钮没有反应？

**A：**

- 确认按钮在地图中正确放置
- 检查按钮与尖刺/传送门/平台是否相连
- 确保玩家踩踏的位置正好是按钮（看屏幕上的高亮）
- 重新测试地图

### Q：我想让多个按钮控制同一个平台，可以吗？

**A：** 暂时不支持。每个按钮只能控制自己的平台组。

### Q：地图可以有多少个房间？

**A：** 理论上无限制，但建议不超过 10 个房间，否则可能加载缓慢。

### Q：如何删除我上传的地图？

**A：**

- 进入地图库
- 找到自己的地图
- 点击地图卡片右下角的"删除"按钮
- 确认删除

### Q：能修改已上传的地图吗？

**A：** 可以，但需要重新上传。步骤：

1. 在编辑器中加载旧地图（从你的编辑历史或通过导入 JSON）
2. 修改内容
3. 重新导出并上传
4. 新版本会覆盖旧版本

### Q：地图的评分和排行榜呢？

**A：** 用户地图暂时没有评分系统。你可以通过与朋友比较通关时间来竞争。

### Q：为什么某些复杂的地图设计无法实现？

**A：** 用户地图系统目前只支持预定义的机制（按钮系统）。如果你想要更复杂的逻辑，可能需要等待未来的功能更新。

## 设计地图的小建议

### 💡 难度设计

**简单地图（新手推荐）：**

- 平台间距不要太远
- 尖刺数量少
- 按钮系统逻辑清晰明了

**中等难度：**

- 需要多次跳跃
- 精准踩踏按钮
- 时间压力（敌人巡逻）

**困难地图（高手挑战）：**

- 紧密的跳跃序列
- 复杂的按钮组合谜题
- 大量敌人

### 🎮 玩家体验

- 提供 **存档点** 避免过长的重试距离
- 用 **文字提示** 指导玩家（如 "踩按钮打开门"）
- 避免 **隐形陷阱**（没有提示的突然尖刺）
- 确保 **没有卡死**（玩家无法推进的位置）

### 🎨 审美设计

- 平衡放置元素，避免某一边空荡
- 按钮和尖刺、传送门要有 **视觉关联**
- 使用 **多房间** 让地图更广阔有趣

## 未来的扩展建议（给开发者）

如果开发团队考虑扩展用户地图系统，可以考虑：

1. **NPC 和对话**
   - 允许用户编写简单对话
   - 支持条件触发的对话

2. **自定义外观**
   - 更多的平台样式
   - 主题颜色定制

3. **评分和社区功能**
   - 玩家给地图评分
   - 最受欢迎地图排行榜
   - 留言和建议

4. **高级机制**
   - 多个按钮的组合逻辑
   - 移动平台
   - 时间限制机制

5. **分享和协作**
   - 多人编辑同一地图
   - 地图版本控制
   - 克隆他人地图进行修改

6. **数据导入/导出**
   - 下载 JSON 文件本地保存
   - 导入文件快速恢复地图
   - 与其他工具兼容

- 🟫 地面

- ⚫ 木箱
- 🔴 尖刺
- 🔵 按钮
- 🟢 传送门
- 📍 传送点

- **保存格式**：JSON

- **兼容性**：可在浏览器中打开和编辑
